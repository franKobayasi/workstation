# 架構審查報告：{對象}

## 1. 摘要

一句總體評語、前三大關鍵發現，以及放行建議：建議放行、有條件放行（列出條件）或建議暫停（列出 blocker）。

## 2. 審查範圍與方法

審查類型、邊界、使用的材料、走查的場景，以及未涵蓋的範圍。

## 3. 架構優勢

做得好且應該保持的設計，至少 2 到 3 項，附理由。

## 4. Findings

依 Critical、High、Medium、Low 排序，每項以下列格式撰寫：

- [{等級}] {標題}
  - 觀察：看到什麼，在哪裡（圖、文件或程式碼的位置）
  - 影響：威脅哪個品質屬性或業務目標，代價估計
  - 建議：具體行動、工作量（S/M/L）、替代選項
