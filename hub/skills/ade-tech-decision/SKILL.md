# 技術決策

共同原則見[架構工作](kb:process/607817)，流程的規則見[重大技術決策的規則](kb:process/8b58b1)，比較方法見[技術選型評估](kb:process/d90b9b)。本 skill 只寫執行步驟，不重述規則。

每個步驟完成後摘要產出，用 `AskUserQuestion` 請使用者確認，確認後才進入下一步。

1. **讀規則**：讀上述三份知識。
2. **界定決策**：依「界定決策」寫出決策陳述，判定可逆性，確認期限與角色。屬於雙向門時告訴使用者，改依[技術選型評估](kb:process/d90b9b)做輕量比較，產出評估報告後結束。
3. **快速過濾**：依「快速過濾」檢查標準與既有 ADR，任一成立時說明依據，依 `ade-create-adr` 寫精簡的 ADR 後結束。
4. **準則與選項**：依「準則與選項」建立準則與權重，先請使用者確認權重，再列出選項。
5. **評估與驗證**：產出加權評分矩陣；需要 PoC 時寫出 PoC 計畫交給使用者執行，取得結果後更新矩陣。
6. **撰寫 RFC**：以本 skill 目錄的 `template.md` 撰寫 RFC，存放位置詢問使用者。同時產出審閱指引：該找誰看、看什麼、截止日，由使用者帶回團隊徵詢。
7. **收斂意見**：使用者帶回意見後，依「RFC 與徵詢」分類處理並更新 RFC，由 decider 做出決定。
8. **落地**：依 `ade-create-adr` 記錄決策並連結 RFC；依「落地與回顧」把 rollout plan 拆成任務，寫下重審的觸發條件與先導階段的成功與失敗指標。
